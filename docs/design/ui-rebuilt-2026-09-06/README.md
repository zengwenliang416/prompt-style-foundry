## 视觉审核与实现纠正项

已逐张查看真实图像。暖纸张、深青、琥珀与工程线条方向保留；以下问题不得从图片直接搬进实现：

- 共性：独立生成的 logo、侧栏宽度、字号和图标不完全一致。实现采用统一品牌和共享 Shell，不逐图复制差异。
- 发现页：模型生成 P- 开头编号、品牌缩略图和虚构文字；正式界面使用当前目录真实 case/framework ID、预览和来源，不将示意缩略图入库。
- 工作台：底部错误画出 `/v1/chat/completions`，单图直连应由实现使用 `/v1/images/edits`；相机品牌、规格、尺寸标注和文件大小是示意，不是实测输入事实。输入/输出画布也不能作为比例保持验收证据。
- 工作区：草稿行画了下载图标，正式实现按真实结果可用性禁用；接口超时不能直接等于失败，应依照 outcome_unknown 规范处理。
- 指南：OPC-TPL 编号、example.com 来源和作者为虚构示例，不是来源证据；提示词被分成 `[System]`/`[Prompt]`，公共模板必须使用 `[System / Prompt]`。蓝图类型说明已出现，没有“禁止直接图生图”错误禁令。
