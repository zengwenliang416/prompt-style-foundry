# OnePic 五页 DESIGN 规范

- 状态：**用户批准的工作基线**（2026-09-06，「我全部批准」，见 ADR 0003）。原五张设计图缺失（D03 保持未勾选），本规范由持久化的五个页面 prompt 文本（`docs/design/ui-2026-09-05-prompts/`）与已记录的视觉方向推导；与原图的像素级比对永久不可验，列为残余风险（Z04 须列出）。U 阶段验收以本规范为对照基准。
- 依据清单项：D04。适用范围：五页前端（U01–U12）。

## 1. 设计方向（可追溯事实）

来自 prompt 文本共同段：暖象牙背景、深色墨色文字、克制的深青（teal）与琥珀（amber）强调、编辑感中文衬线标题、干净中文正文、细蓝图（blueprint）线条装饰；无紫色；无设备框/透视；2x 桌面稿 3072×2048，正文 24px 等效（即 CSS 12px 基准仅供参考，实际见 §2）；减少噪点测量标记，改善留白与对比。

| token | 提案值 | 用途 |

约束：无外部字体、无运行时 CDN（AGENTS §7）；色彩对比度须过 WCAG AA（正文 ≥4.5:1），`prefers-reduced-motion` 下降级动效。

## 3. 布局与断点

- 断点：320 / 768 / 1440（与 U12 验收一致）。≥1024：五页均含侧边导航 + 主区（总览另有工具栏 rail）；<1024：导航折叠为顶栏，masonry 降列；<640：单列，操作条吸底。
- 公共壳：五链接导航 总览 / 模板发现 / 生成工作台 / 我的工作区 / 使用指南；品牌「一图万式」+ 不显眼徽标「设计概念」；键盘可达、焦点可见。

## 4. 页面规格（源自五个 prompt 文本）

1. **总览 /**：侧栏 + 主区 + 工具 rail；「隐私优先 / 无需登录」卡；主标题「一张图，开启更多视觉可能」；上传 dropzone「选择一张参考图 / 图片仅在点击生成后发送至你的接口」；真实统计 576 全部模板 / 文生图蓝图 / 图生图蓝图 / 本地收藏数（未配置服务不展示虚假在线数）；推荐模板四张缩略图；使用方式 01 选模板 02 上传一张图 03 确认生成；接口未配置态。
2. **模板发现 /discover**：图片主导的 masonry + 分类 rail；标题「为你的图片，找到下一种表达」；筛选「原始蓝图类型」chips（全部 / 文生图蓝图 / 图生图蓝图，数量随 catalog 实际值）；搜索「标题、风格、场景或编号」；分类 海报与排版 / 摄影与写实 / 界面设计 / 插画艺术 / 商品与电商；卡片含标题、case ID、蓝图徽标、收藏、查看模板；无人气数、无登录头像。
3. **生成工作台 /studio/:id**：三列 输入 / 结果画布 / 提示词检视 + 底部操作条；恰好一张输入图（示例标记）；提示词检视 tabs「单图模板 / 示例实际提示词」，正文以 `[System / Prompt]` 开头并含 BEGIN/END VISUAL BLUEPRINT；蓝图类型标注「原始分类，不改变单图输入规则」；底部 模型 / 质量 / 比例=继承参考图 / 配置接口 / 生成图片 / 下载结果；明示「点击生成后，图片与提示词直连你配置的接口」；无 seed、滑杆、虚构 token 估算。
4. **我的工作区 /workspace**：副标题「收藏与记录，仅保存在当前浏览器」；侧栏 本地收藏 / 最近查看 / 生成记录 / 本地集合；工具条 导出本地记录 / 导入记录；记录行区分 完成 / 失败 / 草稿，失败行提供显式「重试」、不伪造可下载；空集合态「暂无本地集合」；底部隐私提示「清理浏览器数据可能移除记录」。
5. **使用指南 /guide**：标题「图片决定内容，蓝图决定风格」；流程图 上传一张图片 + 选择视觉蓝图 → 生成结果；优先级 单图规则 > 模板视觉蓝图 > 示例内容；来源信息 模板编号 / 作者署名 / 上游链接 / MIT 许可；提示词结构展示；蓝图类型说明卡；页脚「数据只在你点击生成后直连自定义接口」；提及 Nano Banana Pro 为可用时的首选而非唯一；**禁止出现「禁止直接图生图」类错误文案**。

## 5. 组件与状态

- 组件（U01）：Button（primary/secondary/danger，含 loading/disabled）、Input、Dialog（焦点圈定、Esc 关闭）、Card、Toast、Chip、Tabs、Dropzone、空态/错误页（U02）。
- 任务状态（U09）：排队 / 运行 / 未知 / 失败 / 取消请求 / 成功 / 结果过期；未知态不提供「一键自动重试」；取消如实表述「已请求取消，不保证免计费」。
- 异常态：网络失败、剪贴板拒绝、localStorage 不可用、坏 JSON 导入、格式/大小超限、比例不支持提示。

## 6. 无障碍

语义标签与可访问名称；全键盘操作路径覆盖卡片、筛选、Dialog、复制、下载、收藏；焦点顺序与可见焦点环；减少动效偏好；长文案与 200% 缩放不破版（U12 回归项）。
