# OnePic 五页 DESIGN 规范

- 状态：**已实现且经用户批准的工作基线**（2026-09-06，「我全部批准」，见 ADR 0003）。2026-09-05 原五张设计图仍不可恢复；用户批准的重建五图、实际请求 prompt、metadata 与 SHA256 已落在 `docs/design/ui-rebuilt-2026-09-06/`，D03/D04/U12 均已据此完成。不得把重建图宣称为原图或像素级复刻。
- 依据清单项：D03、D04、U01–U12；实现位于 `apps/web/`，多视口证据位于 `docs/design/evidence/u12/`。

## 1. 设计方向（可追溯事实）

来自 prompt 文本共同段：暖象牙背景、深色墨色文字、克制的深青（teal）与琥珀（amber）强调、编辑感中文衬线标题、干净中文正文、细蓝图（blueprint）线条装饰；无紫色；无设备框/透视；2x 桌面稿 3072×2048，正文 24px 等效（即 CSS 12px 基准仅供参考，实际见 §2）；减少噪点测量标记，改善留白与对比。

## 3. 布局与断点

- 断点：320 / 768 / 1440（与 U12 验收一致）。≥1024：五页均含侧边导航 + 主区（总览另有工具栏 rail）；<1024：导航折叠为顶栏，masonry 降列；<640：单列，操作条吸底。
- 公共壳：五链接导航 总览 / 模板发现 / 生成工作台 / 我的工作区 / 使用指南；品牌「一图万式」+ 不显眼徽标「设计概念」；键盘可达、焦点可见。

## 4. 页面规格（源自五个 prompt 文本）

1. **总览 /**：侧栏 + 主区 + 工具 rail；主标题「一张图，开启更多视觉可能」；上传入口和真实统计 576 全部模板 / 文生图蓝图 / 图生图蓝图 / 本地收藏数；推荐模板和三步使用方式。数据去向按当前模式表达：catalog-only 不上传，direct-BYOK 只在点击生成后直连自定义接口，managed 只在显式触发后经受控 API；未配置服务不展示虚假在线数。
2. **模板发现 /discover**：图片主导的 masonry + 分类 rail；标题「为你的图片，找到下一种表达」；筛选「原始蓝图类型」chips（全部 / 文生图蓝图 / 图生图蓝图，数量随 catalog 实际值）；搜索「标题、风格、场景或编号」；分类 海报与排版 / 摄影与写实 / 界面设计 / 插画艺术 / 商品与电商；卡片含标题、case ID、蓝图徽标、收藏、查看模板；无人气数、无登录头像。
3. **生成工作台 /studio/:id**：三列 输入 / 结果画布 / 提示词检视 + 底部操作条；恰好一张输入图；提示词 tabs 展示编译协议与实际发送事实；比例继承参考图；支持 catalog-only、direct-BYOK、managed-generation。每种模式都明确数据去向；managed 状态覆盖 queued/running/outcome_unknown/failed/cancelled/succeeded/expired，不把请求质量冒充实际像素。
4. **我的工作区 /workspace**：浏览器本地收藏、最近、集合和导入/导出始终可用；明确提示清理浏览器数据的风险。managed mode 只在用户显式点击后把允许的收藏/集合字段导入服务器，展示逐项结果；不迁移 BYOK key，不暗示所有本地数据已跨设备同步。
5. **使用指南 /guide**：标题「图片决定内容，蓝图决定风格」；展示单图优先级、prompt 结构和蓝图类型，不展示逐模板作者、仓库、来源链接或许可归属；并列说明目录浏览、BYOK 直连和受管生成的真实数据去向。Nano Banana Pro 只作为可用时首选；**禁止出现「禁止直接图生图」类错误文案**，也禁止把 managed 请求描述成直连自定义接口。

## 5. 组件与状态

- 组件（U01）：Button（primary/secondary/danger，含 loading/disabled）、Input、Dialog（焦点圈定、Esc 关闭）、Card、Toast、Chip、Tabs、Dropzone、空态/错误页（U02）。
- 任务状态（U09）：排队 / 运行 / 未知 / 失败 / 取消请求 / 成功 / 结果过期；未知态不提供「一键自动重试」；取消如实表述「已请求取消，不保证免计费」。
- 异常态：网络失败、剪贴板拒绝、localStorage 不可用、坏 JSON 导入、格式/大小超限、比例不支持提示。

## 6. 无障碍

语义标签与可访问名称；全键盘操作路径覆盖卡片、筛选、Dialog、复制、下载、收藏；焦点顺序与可见焦点环；减少动效偏好；长文案与 200% 缩放不破版（U12 回归项）。

## 7. 保留偏差与残余风险

- 2026-09-05 原图不可恢复；当前只可与用户批准的 2026-09-06 重建基线比较，不宣称原图像素级保真。
- 色值、字号、间距、rail 宽度和移动端排布以已实现 CSS 与 U12 的 320/768/1440、200% zoom、长文案、reduced-motion 实测为当前事实。
- 重建图本身不覆盖全部动态、异常和授权状态；这些状态以组件/浏览器测试及持久截图为准。
